# Web Reader 1.8.10 hotfix.11 — 통계 완료 상태·포인트 색상 정리

작성일: 2026-08-13

기준 커밋: `eab2c16`

상위 문서: [update_1.8.10.md](./update_1.8.10.md)

상태: 구현·자동검증 완료. 실기기 확인 대기

## 실사용 finding

- 도서별 기록의 작은 `완료` 글자가 동작 버튼인지 이미 끝난 상태인지 구분하기 어려웠다.
- 통계 모달의 선택 상태와 주요 수치·동작 색상이 섞여 있어 사용자가 설정한 포인트 색상이 충분히 드러나지 않았다.

## 변경

- 완료 가능한 최신 회차의 동작을 `완료하기`로 표시한다.
- 명시적으로 닫힌 회차의 상태를 `완료됨`으로 표시하고, 누르면 기존처럼 시작일·종료일 상세를 펼친다.
- 두 완료 표시는 모바일에서도 바로 읽을 수 있도록 글자 크기와 배경 대비를 높였다.
- 새로고침, 기간 선택, 도서 필터 선택, 핵심 시간 수치, 완료 상태·동작, 내보내기·공유·진단 버튼의 강조 부분에 현재 설정의 포인트 색상을 사용한다.
- 서비스 워커 스크립트를 갱신해 설치형 PWA도 UI 변경을 감지한다.

## 자동검증

- production browser regression에서 완료된 회차가 `완료됨`, 완료 가능한 회차가 `완료하기`로 구분되는지 확인한다.
- `npm run check` 및 production build를 통과한다.
- `git diff --check`를 통과한다.

## 실기기 확인

- Android·iPad에서 `완료하기`와 `완료됨`의 크기·대비가 충분한지 확인한다.
- 밝은·어두운 테마와 각 포인트 색상에서 버튼·강조 수치가 자연스럽게 보이는지 확인한다.
