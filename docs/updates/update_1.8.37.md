# Web Reader 1.8.37 — 진행률 임시 이동·본문 미리보기

작성일: 2026-09-09

상태: 구현 완료 · 로컬 자동검증 통과

## 동작

- 슬라이더를 놓으면 본문은 선택 위치로 이동하고 확인 패널을 표시한다. 확인 전에는 새 위치를 진행도·동기화에 저장하지 않는다.
- 여러 번 움직여도 최초 출발 위치를 유지한다. 30→40→50→60에서 취소하면 30으로 돌아간다. 확인하면 현재 임시 위치와 최초 위치의 자동 책갈피를 저장한다.
- 확인 패널은 바깥 클릭으로 닫히지 않으며 배경 입력이나 키보드 포커스를 가두지 않는다. 진행률·목차·검색·책갈피 메뉴를 계속 사용할 수 있다. 임시 상태의 메뉴 이동도 같은 순서로 실행해 취소·확정과 경합하지 않게 한다.
- 임시 상태에는 자동 저장, 강제 저장, 화면 숨김·종료 저장, 외부 progress flush와 원격 진행률 이동을 차단한다. 취소 시 원래 대기 중이던 저장은 복원한다. 수동 책갈피 편집은 독립적으로 유지한다.
- 드래그 중 화면 중앙에 약 절반 크기의 반투명 미리보기를 표시한다. EPUB/TXT는 해당 위치 근처 본문, PDF/ZIP/CBZ/7z는 해당 페이지 이미지를 보여 준다. 텍스트는 장 내부 문자 비율을 사용하므로 실제 페이지 시작 문장과 완전히 같지는 않을 수 있다.
- 미리보기는 독립 소스로 추출하며 본문을 이동하지 않는다. 요청 지연·직렬 실행·취소와 임시 URL 해제로 오래된 결과 및 이미지 자원 누적을 막는다.

## 검증

- lint·TypeScript·production build 통과. 버전 기대값과 변경된 비모달 계약의 실패는 해당 파일을 수정해 재검증하고 나머지 성공 결과는 재사용했다.
- Node 테스트 722개 및 Python 테스트 3개 통과. 임시 이동 저장 차단·연속 이동·취소 경합·확인 중 수동 책갈피 편집·미리보기 취소와 자원 수명 회귀를 포함한다.
- Firestore Rules 36개 통과. Rules 소스 변경이나 배포는 없다.
- Playwright E2E 38개 통과, 기존 WebKit 파일 Blob 제약 2개 생략.
- 전체 production browser regression 통과: 확인 전 실제 위치 이동, 저장 없음, 원래 CFI 복귀, 드래그 본문 미리보기, PDF 이미지 생성·취소 및 기존 TTS/주석/통계/PWA 경로.
- macOS에서 직접 실행한 Chromium의 animation frame이 멈춰 기존 독서 인증 이미지 검사에서 대기했다. 최소 frame probe와 진단으로 확인 후 검증 실행기를 Playwright의 headless launch로 전환했고 전체 회귀가 통과했다. 앱 코드나 성공 조건은 완화하지 않았다.
- 실제 Android/iPad 기기의 터치·PDF 렌더링 확인은 자동검증과 별도로 남긴다.

## 정밀 진행률 이동

- 누르는 순간에는 현재 진행률을 유지한다. 짧은 탭은 손을 뗄 때 찍은 위치로 이동하고, 드래그는 현재 진행률에서 손의 가로 이동량만큼 움직인다. 움직임 없이 350ms 누르면 찍은 위치를 새 시작점으로 선택하고, 이후 드래그를 그 위치에서 이어간다. 누른 채 바 위쪽으로 48px 이상 올리면 수평 이동 감도를 1/5로 낮추고, 바 아래쪽으로 48px 이상 내리면 1/10로 낮춘다.
- 정밀 이동 진입·종료에서 현재 선택 위치를 이어받아 위치가 튀지 않는다. 다시 바 쪽 24px 이내로 내려오면 일반 감도로 복귀하며, 다음 새 터치도 현재 진행률에서 시작한다.
- 진입/종료 경계를 다르게 두어 손떨림으로 모드가 반복 전환되지 않게 하고 작은 움직임을 누적한다. 현재 모드는 `일반 이동`, `1/5 정밀 이동`, `1/10 정밀 이동`만 표시하며 미리보기와 분리한 화면 하단의 작은 타원 배지로 표시한다. 기존 메뉴의 글래스 재질을 사용하고 미리보기보다 위에 표시하며 터치를 가로채지 않는다.
- 실제 pointer 이벤트 회귀 9개 통과: 일반 이동, 위쪽 1/5·아래쪽 1/10 감도, 수직 전환 위치 유지, 경계 떨림, 복귀 감도, 새 터치 초기화와 기존 임시 이동 계약.

- 수직 방향이 뚜렷한 드래그와 감도 전환에서는 진행률을 고정한다. 가로 흔들림을 버리고, 좌우 이동 의도가 확인되면 현재 위치에서 해당 감도로 이어간다. 작은 좌우 움직임도 누적해 느린 정밀 이동을 허용한다.

## 도서 형식 필터

- 정렬·필터에서 도서 출처 위에 TXT, EPUB, PDF, ZIP 복수 선택을 추가했다. 선택하지 않으면 전체 형식을 보여주며 출처·장르·태그 조건과 함께 적용한다.
- 변환된 TXT는 원본 형식으로 분류하고 이미지 압축 도서(ZIP/CBZ/7Z)는 ZIP에 묶는다. 카탈로그 로딩 상태와 관계없이 사용할 수 있으며 선택 수·검색·초기화에도 반영한다.
