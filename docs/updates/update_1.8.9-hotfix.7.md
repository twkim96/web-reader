## 목표

태블릿 가로 화면에서 EPUB 본문 최대폭 바깥의 좌우 여백도 탭 이동 영역으로 동작하게 한다. 사용자가 명시적으로 선택한 경우에만 탭 이동 모드의 가로 화면을 두 페이지로 표시하고, 기존 1페이지 기본값과 세로 화면 동작은 유지한다.

## 실기기 finding과 수정

### 1. 넓은 화면의 본문 바깥 탭 누락

기존 탭 이동 처리는 publication iframe 문서에 설치됐다. EPUB 본문은 최대 1000px 폭으로 제한되므로 약 1200px 이상의 가로 화면에서는 좌우 여백이 iframe 바깥에 생겼고, 해당 영역의 탭은 리더 이동 로직까지 도달하지 않았다.

수정 결과:

- reflowable EPUB의 리더 컨테이너에도 기존 탭 판정 함수를 연결했다.
- iframe 안의 본문 탭은 문서별 selection·link·highlight 경로를 그대로 사용한다.
- iframe 바깥 좌우 여백 탭만 컨테이너 경로가 받아 중복 이동 없이 이전·다음 페이지로 처리한다.
- fixed-layout 도서는 기존 전용 overlay를 유지하며 이번 경로를 적용하지 않는다.

### 2. 선택형 가로 2페이지 보기

- 리더 설정에 `가로 모드 2페이지 보기` 체크박스를 추가했다.
- 기본값은 미체크이며 기존 저장값에도 자동 활성화되지 않는다.
- 체크해도 스크롤 모드에서는 1열을 유지한다.
- 탭 이동 모드에서는 리더 컨테이너가 가로일 때 최대 2열, 세로일 때 1열로 자동 전환한다.
- 설정은 기존 `viewer_settings`에 boolean으로 저장하며 잘못된 문자열 값은 활성화로 해석하지 않는다.
- fixed-layout 도서는 설정 대상에서 제외한다.

## 실기기 검증 대기

- iPad/Android 태블릿 가로 화면에서 본문 좌우의 빈 여백을 짧게 탭했을 때 한 번만 이동하는지 확인한다.
- 여백의 길게 누르기·드래그가 본문 선택이나 하이라이트 메뉴를 오작동시키지 않는지 확인한다.
- 옵션 OFF에서 기존 1페이지 레이아웃이 유지되는지 확인한다.
- 옵션 ON에서 탭 이동 모드 가로 2페이지, 회전 후 세로 1페이지, 다시 가로 2페이지가 위치 손실 없이 전환되는지 확인한다.
- Safari 탭과 홈 화면 PWA에서 회전 직후 페이지 순서, 중앙 여백, 이전·다음 탭 방향을 확인한다.
