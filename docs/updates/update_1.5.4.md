# update 1.5.4

## 목표

shelf의 도서 추가 모달을 드래그앤드롭 중심으로 개선한다. 파일 시스템 선택 또는 드롭은 즉시 저장하지 않고 모달 안의 선택 리스트에만 추가하며, 사용자가 `추가` 버튼을 눌렀을 때만 로컬 저장/클라우드 업로드를 실행한다.

## Phase 1: 업로드 처리 공통화

- 실제 저장/동기화 로직은 `FileList | File[]` 공통 처리 함수로 확장한다.
- 드롭 파일과 파일 선택 결과는 먼저 모달 리스트에만 추가하고, `추가` 버튼에서 같은 저장/동기화 경로를 사용하게 한다.
- 한 번에 추가 가능한 도서는 최대 10개로 제한한다.
- 파일 하나의 최대 용량은 50MB로 제한한다.
- 선택 리스트의 총 용량은 200MB로 제한한다.
- 기존 선택 파일이 9개인 상태에서 2개를 더 추가하는 것처럼 한도를 넘는 추가 시도는 해당 묶음 전체를 거부한다.
- 개수, 개별 용량, 총 용량 중 하나라도 제한을 넘으면 해당 선택 묶음 전체를 거부한다.
- `.txt`, `.epub`만 처리하고 그 외 파일은 안내한다.

## Phase 2: import 모달 UI

- 기존 확인 모달 대신 shelf 전용 import 모달을 사용한다.
- 상단 안내 아이콘 아래에 큰 + 드롭존을 배치한다.
- 드롭존은 drag hover 상태를 시각적으로 표시한다.
- + 드롭존을 누르면 파일 시스템 선택창을 열고, 선택한 파일은 리스트에만 추가한다.
- 드롭존 아래에 구분선을 두고 선택된 도서 리스트를 표시한다.
- 드롭존은 모달 폭에 맞춰 중앙 정렬하고 높이를 줄인다.
- 선택 도서 리스트는 3개 항목이 보이는 고정 높이 영역으로 표시한다.
- 기존 `업로드` 버튼 문구는 실제 실행 의미에 맞게 `추가`로 변경한다.
- 오프라인/게스트 안내 문구와 클라우드 로그인/연결 동선은 유지한다.

- 브라우저에서 도서 추가 모달, 드롭존, 업로드 버튼 노출을 확인한다.
