# update 1.5.5

## 목표

커스텀 테마의 텍스처 설정을 EPUB 리더 내부까지 적용하고, 텍스처 선택 UI를 6개 옵션으로 확장한다.

## 변경 내용

- 커스텀 테마 텍스처 옵션을 `없음`, `종이`, `섬유`, `캔버스`, `격자`, `입자` 6개로 확장한다.
- 예시 이미지에 가까운 어두운 직물 느낌의 `캔버스` 텍스처를 CSS gradient 조합으로 추가한다.
- 텍스처 버튼은 3개씩 2줄로 배치한다.
- 커스텀 테마 편집 모달의 `배경색`과 `글자색` 입력을 한 줄로 합친다.
- 모달 패딩, 입력 높이, 버튼 높이, 미리보기 여백을 줄여 텍스처 버튼 한 줄이 추가되어도 전체 크기가 크게 늘지 않게 한다.
- 커스텀 테마 미리보기와 테마 카드에도 선택한 텍스처를 표시한다.
- EPUB 리더 내부 foliate 문서에도 `background-image`, `background-size`를 주입해 실제 본문 배경에 텍스처가 보이게 한다.

## 검증

- `git diff --check`
- `npx tsc --noEmit`
- `npx eslint src`
- `npm run build`
- 브라우저에서 커스텀 테마 추가 모달의 색상 입력 1줄 배치, 텍스처 6개/2줄 배치, `캔버스` 미리보기 gradient 적용을 확인한다.
