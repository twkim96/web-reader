# Web Reader 1.8.10 hotfix.12 — 통계 포인트 색상 결합·강조 절제

작성일: 2026-08-14

기준 커밋: `b5fc218`

상위 문서: [update_1.8.10.md](./update_1.8.10.md)

상태: 구현·자동검증 완료. 실기기 확인 대기

## 실사용 finding

- 통계 모달의 포인트 요소가 설정에서 선택한 색상 대신 기본 파란색처럼 보일 수 있었다.
- hotfix.11에서 MD·JSON·진단 보조 버튼의 테두리까지 포인트색으로 바뀌어 화면 전체의 색상 강조가 과했다.

## 변경

- 통계 모달에 현재 `accentColor` 설정을 명시적으로 전달한다.
- 모달 루트에 해당 팔레트의 `--accent-400/500/600`을 직접 설정해 책장·리더 어느 진입점에서도 같은 포인트색을 사용한다.
- 포인트색은 선택된 기간·필터, 핵심 시간 수치, 새로고침, 완료 상태·동작과 버튼 글자·아이콘에만 사용한다.
- MD·JSON·진단 버튼의 테두리는 현재 테마의 중립 테두리로 복원한다. 공유 버튼만 기존처럼 채워진 핵심 동작으로 유지한다.
- 서비스 워커 스크립트를 갱신해 설치형 PWA도 변경을 감지한다.

## 자동검증

- emerald 설정 상태에서 통계 모달이 `#10b981`을 직접 사용하는지 확인한다.
- 보조 버튼 글자·아이콘은 포인트색이되 테두리는 같은 포인트색이 아닌지 확인한다.
- `npm run check` 및 production browser regression을 통과한다.
- `git diff --check`를 통과한다.

## 실기기 확인

- Android·iPad에서 테마 설정의 포인트색을 바꾼 직후 통계 모달의 강조색도 함께 바뀌는지 확인한다.
- MD·JSON·진단 테두리가 중립색으로 보여 화면이 과도하게 색칠되지 않는지 확인한다.
