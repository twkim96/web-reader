# 버전별 개발 기록

Web Reader의 버전 계획, 구현 범위, 리뷰 결과, 자동검증과 실기기 확인 기록을 보관한다.

## 작성 규칙

- 새 문서는 저장소 루트가 아니라 이 폴더에 만든다.
- 정식 버전은 `update_<version>.md` 형식을 사용한다. 예: `update_1.8.2.md`.
- 안정화 패치는 `update_<version>-hotfix.<number>.md` 형식을 사용한다.
- 버전군 전체 계획은 `update_<series>.x_plan.md` 형식을 사용한다.
- 구현 완료, 자동검증 완료와 실기기 검증 완료를 구분해 기록한다.
- 새 문서에서 상위 계획과 후속 문서는 같은 폴더의 상대 링크로 연결한다.
- 공백이 들어간 1.5.x 초기 파일명과 중복 버전 문서는 과거 이력 보존을 위해 합치거나 이름을 바꾸지 않는다.
