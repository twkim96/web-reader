# Web Reader 1.8.31 — 책장 표지 레이아웃 개선

## 문제

책장 리스트뷰에서 표지가 없는 행은 기존 텍스트/아이콘 높이 기준으로 약 84px인데, 캐시된 세로 표지가 있는 행은 데스크톱에서 `sm:h-[4.25rem]`(68px) + 카드 `sm:py-3`(상하 12px) 때문에 약 92px까지 커졌다.

그 결과 표지가 생긴 도서만 리스트 행 높이가 달라져 줄 간격이 흔들려 보였다.

## 수정

- 표지 실제 크기 `68px × 48px`은 유지한다.
- 데스크톱 리스트 표지에 `sm:-my-1`을 적용한다.
- 표지 자체는 위아래로 4px씩 카드 padding 영역을 사용하지만, grid 레이아웃에서 차지하는 외부 높이는 60px으로 계산된다.
- 따라서 표지 기준 행 높이는 `60 + 12 + 12 = 84px`이 되어 기존 리스트 행과 맞는다.
- 모바일은 기존 `64px` 표지 + `py-2.5` 조합이 이미 약 84px이므로 변경하지 않는다.
- 표지 폭/높이, `object-cover`, borderless 스타일은 그대로 유지한다.

## 그리드/도서 정보 후속 조정

- 같은 1.8.31에서 그리드 카드의 캐시 표지를 작은 아이콘 크기에서 벗어나 크게 보여준다.
- 표지가 있는 그리드 카드는 좌측 `96×144px`, `sm` 이상 `112×160px` 세로 표지와 우측 제목/형식/태그/조회수의 2열 헤더를 사용한다.
- 표지가 없는 그리드 카드는 기존 아이콘/제목 구조를 유지한다.
- 도서 정보 모달은 `book-covers-v14`만 읽어 캐시 표지가 있으면 제목 왼쪽에 `72×112px`, `sm` 이상 `84×128px` 썸네일을 표시한다.
- 도서 정보 모달에서 표지를 위해 네트워크 요청을 새로 만들지 않는다.
- `public/sw.js` 내용도 같은 1.8.31에서 갱신해 기존 설치형 PWA가 동일 버전의 후속 UI 변경을 감지할 수 있게 한다.

## 검증

- `tests/bookCardLayout.test.mjs`에서 데스크톱 리스트 표지의 `sm:-my-1`과 그리드 2열/대형 표지 크기를 함께 검증한다.
- release/cache version은 `1.8.31`을 유지한다.
