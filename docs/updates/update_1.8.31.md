# Web Reader 1.8.31 — 책장 표지 레이아웃 개선

## 문제

책장 리스트뷰에서 표지가 없는 행은 기존 텍스트/아이콘 높이 기준으로 약 84px인데, 캐시된 세로 표지가 있는 행은 데스크톱에서 `sm:h-[4.25rem]`(68px) + 카드 `sm:py-3`(상하 12px) 때문에 약 92px까지 커졌다.

그 결과 표지가 생긴 도서만 리스트 행 높이가 달라져 줄 간격이 흔들려 보였다.

## 수정

- 표지 실제 크기 `68px × 48px`은 유지한다.
- 데스크톱 리스트 표지에 `sm:-my-1`을 적용한다.
- 표지 자체는 위아래로 4px씩 카드 padding 영역을 사용하지만, grid 레이아웃에서 차지하는 외부 높이는 60px으로 계산된다.
- 따라서 표지 기준 행 높이는 `60 + 12 + 12 = 84px`이 되어 기존 리스트 행과 맞는다.
- 모바일은 기존 `64px` 표지 + `py-2.5` 조합이 이미 약 84px이므로 변경하지 않는다.
- 표지 폭/높이, `object-cover`, borderless 스타일은 그대로 유지한다.

## 그리드/도서 정보 후속 조정

- 같은 1.8.31에서 그리드 카드의 캐시 표지를 작은 아이콘 크기에서 벗어나 크게 보여준다.
- 실제 표지 캐시가 없는 도서도 책 아이콘으로 분기하지 않고, 도서 id를 deterministic hash한 고채도 단색 팔레트와 책 제목으로 임시 표지를 만든다. 같은 도서는 새로고침해도 같은 색을 사용하며, 표지색 luminance에 따라 흰색/검은색 제목을 골라 최소 4.5:1 대비를 유지한다. 임시표지 제목은 `font-black(900)`보다 두 단계 얇은 `font-bold(700)`을 사용한다.
- 임시 표지는 실제 표지와 동일한 리스트/그리드 프레임을 사용한다. 실제 `book-covers-v14` 표지가 생기면 즉시 실제 이미지가 우선하고 임시 표지는 사라진다.
- 도서 정보 모달도 캐시 표지가 없으면 동일한 임시 표지를 제목 옆 썸네일에 사용해 Shelf와 시각 체계를 통일한다. 우측 제목/파일명 컬럼은 표지 높이를 최소 높이로 사용하고, `TXT / 기기 저장됨 / 플랫폼` 태그 행을 `mt-auto`로 내려 표지 하단선에 맞춘다.
- 표지가 있는 그리드 카드는 좌측 `96×144px`, `sm` 이상 `112×160px` 세로 표지와 우측 제목/형식/조회수의 2열 헤더를 사용한다.
- 우측 제목은 기존 2줄보다 넓게 최대 4줄까지 사용하고, 큰 우상단 로컬 체크를 제거해 그 폭을 제목에 돌려준다.
- 표지가 있는 그리드 카드의 우측 열은 표지와 같은 `144/160px` 높이의 flex column으로 만들고, `TXT → 조회수` 메타 블록을 `mt-auto`로 내려 조회수 줄의 하단이 표지 하단과 맞도록 한다. `TXT`와 조회수 사이는 기존 `mt-2` 간격을 유지한다.
- 기기 로컬 상태는 별도 아이콘/열 대신 초록색 `로컬` 태그로 장르 앞에 표시한다.
- 장르/태그는 헤더 아래 카드 전체 폭으로 내려 표지 아래 빈 공간을 활용하며, 개수 기준으로 자르지 않고 실제 렌더링 높이를 최대 2줄(`max-h-9`)로 잘라 3번째 줄부터는 보이지 않게 한다.
- 후속 실기기 조정에서 태그 슬롯의 `flex-1` 강제 확장을 제거하고 `mt-2 min-h-9`의 자연 높이만 사용해 태그와 진행률 사이의 큰 빈 공간을 없앤다.
- 그리드 카드 padding은 `p-8`에서 `p-6`로 줄이고 progress block은 `mt-auto pt-3 space-y-2`로 압축해 같은 grid row의 진행률 Y 정렬은 유지하면서 카드 전체 높이를 더 줄인다.
- 진행률 행의 우측 퍼센트는 날짜와 같은 하단 기준선을 유지하고, 삭제 지우개는 큰 `p-2` 버튼 대신 고정 `20×20px` 버튼으로 바꿔 퍼센트 옆에서 위로 떠 보이지 않게 한다.
- 표지가 없는 그리드 카드도 별도 로컬 체크를 사용하지 않고 같은 초록색 `로컬` 태그를 장르 앞에 표시한다.
- 리스트 데스크톱은 `표지 | 제목·태그·날짜 | 형식 | 조회수·진행도`의 4열로 재배치한다. 제목 열은 `minmax(0,1fr)`로 남는 폭을 전부 쓰고 우측은 `4rem / 10rem`만 고정한다.
- 리스트의 visible chip 상한은 `로컬 + 장르 + 일반 태그`를 모두 합쳐 최대 10개다. 일반 태그 수를 고정 5개로 자르지 않고 10개 상한 안에서 가능한 만큼 표시하며, 모바일은 실제 너비 측정으로 더 줄이고 `+N`을 남긴다.
- 리스트 모바일/데스크톱 모두 로컬 상태를 제목 옆 체크나 별도 열이 아니라 동일한 초록색 `로컬` 태그로 표현한다.
- 도서 정보 모달은 `book-covers-v14`만 읽어 캐시 표지가 있으면 제목 왼쪽에 `72×112px`, `sm` 이상 `84×128px` 썸네일을 표시한다. 임시표지 제목은 중앙 정렬 대신 표지 상단 약 15% 지점에서 시작하고, 가장 작은 리스트 임시표지 제목도 `7px`로 올려 가독성을 확보한다.
- 도서 정보 모달에서 표지를 위해 네트워크 요청을 새로 만들지 않는다.
- `public/sw.js` 내용도 같은 1.8.31에서 갱신해 기존 설치형 PWA가 동일 버전의 후속 UI 변경을 감지할 수 있게 한다.

## 검증

- `tests/bookCardLayout.test.mjs`에서 실제/임시 표지가 동일 프레임을 쓰고 기존 책 아이콘이 사라지는지, 임시 표지 색이 deterministic하며 텍스트 대비가 4.5:1 이상인지, 임시표지 제목이 `top-[15%]`에서 시작하고 리스트 variant가 `7px`인지, 제목 굵기가 `font-bold(700)`인지, 데스크톱 리스트 표지의 `sm:-my-1`, 가변 제목+compact 형식/진행도 4열, 초록 `로컬` 태그 선두 배치와 총 10-chip 상한, 그리드 2열/대형 표지, 4줄 제목, 표지 높이와 동일한 우측 flex column, 하단 고정 `TXT/조회수`, 2줄 높이-clipped 태그 영역, compact spacing, 고정 크기 삭제 버튼을 함께 검증한다.
- `tests/browserRegression.mjs`에서 같은 row의 표지 있음/없음 카드 진행률 블록 Y 좌표, 날짜/% 하단 정렬, 표지 하단과 우측 metadata block 하단 정렬, 도서정보 태그 행의 표지 하단 정렬과 임시표지 제목의 15% 시작 위치를 실제 브라우저 좌표로 검증한다.
- Chromium `tests/e2e/bookCoverCache.spec.ts`에서 실제 PDF/CBZ 표지 캐시와 캐시 삭제 후 임시표지 fallback을 검증한다.
- release/cache version은 `1.8.31`을 유지한다.

## 완료 상태

1.8.31은 책장 표지/카드 UI 안정화 릴리스로 마감한다. 실제 표지가 있는 도서와 없는 도서 모두 동일한 표지 슬롯을 사용하고, 무표지 도서는 deterministic 임시표지로 대체한다. 리스트/그리드의 제목·태그·메타데이터·진행률 정렬과 도서정보 썸네일까지 동일한 시각 규칙으로 정리했다.

최종 계약은 다음과 같다.

- Shelf는 실제 표지가 있으면 `book-covers-v14` 캐시를 우선하고, 없으면 저장/네트워크 없이 임시표지를 렌더한다.
- 임시표지는 도서 id에 대해 색상이 안정적이고, 제목은 상단 약 15%에서 시작하며 최소 7px·700 weight를 사용한다.
- 리스트는 약 84px 행 높이를 유지하고, 로컬/장르/일반 태그를 합쳐 최대 10개 chip을 표시한다.
- 그리드는 96×144px / 112×160px 표지, 최대 4줄 제목, 최대 2줄 태그와 compact progress layout을 사용한다.
- 도서정보는 실제/임시 썸네일을 동일 슬롯에 표시하며 메타데이터 태그 행을 표지 하단선에 맞춘다.
- 동일 버전의 후속 UI 변경도 설치형 PWA에서 감지되도록 `public/sw.js` 내용을 함께 갱신한다.

이 문서 이후 1.8.31에는 추가 기능을 넣지 않고, 이후 변경은 다음 patch 버전으로 진행한다.
