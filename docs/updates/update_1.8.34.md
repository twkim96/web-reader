# Web Reader 1.8.34 — 메뉴 모달·모바일 바텀시트 통일

작성일: 2026-08-27

기준 커밋: `ed84a5e`

이전 버전: [1.8.33 EPUB 스크롤 입력 경로 최적화](./update_1.8.33.md)

상위 계획: [1.8.x 전체 계획](./update_1.8.x_plan.md)

## 목표

Shelf와 Reader 메뉴바에서 여는 모달의 정보 구조와 표면을 하나의 규칙으로 통일한다.

- 모바일에서는 좌우·하단 여백을 둔 하단 바텀시트로 표시한다.
- PC에서는 기존 중앙·상단 배치를 유지하되 모바일과 같은 테마 배경·헤더 구조를 사용한다.
- 헤더는 왼쪽 원형 닫기 버튼, 제목·선택적 보조문구, 오른쪽 기능 액션 순서로 통일한다.
- 모달별 장식 아이콘은 제거하고 새로고침·테마 추가처럼 실제 동작이 있는 액션만 남긴다.
- 번역·진행률 이동·주석 편집·설치 안내 등 메뉴바 밖의 작업 대화상자는 기존 배치를 보존한다.

## 적용 범위

상태: 완료

- Shelf: 도서 추가, 정렬·필터, 라이브러리 주석, 독서 통계, 테마 설정, 오프라인 저장소.
- Reader: 리더 설정, 테마 설정, 책갈피·주석, 목차, 독서 통계, 도서 정보.
- Shelf 도서 검색과 Reader 본문 검색은 기존 Spotlight형 검색창 배치와 크기를 유지한다.
- 공통 `MenuSheetHeader`와 `ReaderModalFrame.menuSheet` 계약을 추가한다.
- 640px 미만에서 좌우 20px·하단 12px 이상의 여백을 둔 하단 고정, 최대 높이 60dvh, 전체 22px 곡률과 짧은 페이드 전환을 적용한다. 기존 `animate-in` transform과 중첩되어 시트가 하단 아래로 밀리지 않도록 위치 transform은 명시적으로 제거한다.
- 내용이 60dvh를 넘으면 모달 내부만 스크롤하고, 별도 헤더·하단 실행 영역이 있는 모달은 해당 영역을 고정한다.
- 테마 설정 헤더를 스크롤 영역 밖에 고정하고, 도서 정보·독서 통계의 본문과 하단 실행 영역은 테마 설정과 같은 단일 투명 표면 위에 표시한다.
- 내장 테마 4개는 고정된 한 줄에 표시하고, 커스텀 테마가 늘어나면 커스텀 영역만 스크롤한다. 해당 스크롤이 끝나면 바텀시트 본문 스크롤로 자연스럽게 이어지며, 공통 메뉴 모달은 다른 Shelf 모달처럼 배경의 실제 클릭에서 닫아 뒤 화면 요소로 입력이 관통하지 않는다.
- 공통 모달 닫기 버튼은 40px 터치 영역과 20px 아이콘으로 정리한다.
- Reader 메뉴 시트는 공통 프레임의 중앙 배치를 기본값으로 사용하며, 목차만 위로 치우치던 개별 위치 예외를 제거한다.
- 오프라인 저장소의 도서 행은 공통 메뉴 액션 표면을 사용하고, 글래스 메뉴 표면과 액션에는 밝은 배경에서도 구분되는 얕은 부상 그림자·하이라이트·외곽 대비를 적용한다.
- 글래스 메뉴바의 저블러는 유지하되 모달에만 블러를 4px에서 4.2px로 5% 높여, 배경 투과감과 본문 가독성의 균형을 보완한다.
- 신규 커스텀 테마의 기본 포인트 컬러와 유효하지 않은 커스텀 저장값의 폴백을 `rose` 프리셋으로 통일한다.
- 모달마다 달랐던 검은 오버레이·사전 블러를 테마 설정 기준으로 통일해, 현재 색상 테마 위에 메뉴 스타일 질감이 한 번만 합성되도록 한다.
- 모든 화면 크기에서 모달 표면은 현재 테마색과 함께 메뉴 스타일의 표준 고블러·글래스 저블러·모던 고불투명 질감을 적용한다.
- Shelf의 바텀 메뉴바는 메뉴 시트·Spotlight 검색·일반 확인 대화상자가 열리면 입력을 즉시 차단하고 180ms 동안 아래로 축소·페이드한 뒤 숨긴다. 모달이 닫히면 같은 위치에서 복귀하며, Reader의 기존 메뉴 숨김 동작은 변경하지 않는다.
- 읽기 테마는 `Aa`를 중심으로 한 정사각형 카드 4개를 한 줄에 표시하고, 표시명을 `라이트`·`세피아`·`다크`·`자정`으로 한국어화한다. `자정`은 기존 `midnight` 저장 키를 그대로 사용한다.
- 내장 테마의 포인트 컬러를 라이트·자정은 빨강, 세피아는 초록, 다크는 노랑으로 고정하고, 전역 포인트 컬러 선택 영역은 제거한다.
- 포인트 컬러 선택은 커스텀 테마 생성·편집 화면 안으로 이동한다. 기존 커스텀 테마는 저장된 전역 포인트 컬러를 호환 폴백으로 유지한다.
- `메뉴 스타일 · 책장 / 리더` 표기를 `메뉴 스타일`로 정리하고, 표준·글래스·모던을 실제 질감이 보이는 정사각형 미리보기 카드 3개로 통일한다.

## 검증 계약

- 공통 헤더의 닫기 버튼이 키보드 포커스 가능한 첫 액션으로 노출된다.
- 모바일 시트는 화면 가장자리와 간격을 두고 뜨며 전체 외곽선과 곡률을 유지한다.
- PC 모달의 기존 최대 너비와 배치, 모달별 본문 스크롤은 유지한다.
- backdrop 클릭·Escape·포커스 복귀·body scroll lock 계약을 유지한다.
- 릴리스 버전, 서비스워커, Foliate 런타임 쿼리와 회귀 테스트 버전을 1.8.34로 일치시킨다.
