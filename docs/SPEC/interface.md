# 화면과 디자인

독서 내용을 중심에 두는 조용한 인터페이스를 유지합니다. 작은 컨트롤과 고정 overlay를 사용하고 제스처만 처리하는 영역에 장식 표면을 추가하지 않습니다.

## 테마·설정·재질

첫 화면 기본값은 midnight·rose·glass이며 읽기는 스크롤·RIDIBatang을 기본으로 합니다. 설정은 `viewer_settings`에 기기별로 저장합니다. 폰트·크기·줄/문단 간격·본문 정렬·여백·탭 영역·[자동 두 페이지](reader-and-progress.md#자동-두-페이지)·마지막 도서 자동 열기·언어/음성 설정을 제공합니다. 정확한 기본값과 정규화는 [useViewerSettings.ts](../../src/hooks/useViewerSettings.ts)가 담당합니다.

색 테마(midnight/dark/sepia/light 및 사용자 테마), 메뉴 재질(standard/glass/modern), 배경 질감은 독립 축입니다. 재질은 책장 도크, 리더 상·하단 바, 모달·팝오버·닫기 버튼·액션·푸터에 일관되게 적용합니다. glass의 도크/리더 바와 모달 표면은 다른 레시피입니다. 값은 [globals.css](../../src/app/globals.css), `themeUtils`, `constants`가 기준이며 독립 키트에는 추출 결과를 동기화합니다.

EPUB/TXT의 테마 배경색·질감은 바깥 `EpubReader` 화면에서 한 번 칠합니다. 책 본문 iframe의 `html`·`body`와 paginator 바탕은 투명하게 두어 본문·중앙 간격·좌우/상하 여백까지 같은 배경이 이어집니다. `useFoliateLayout`이 `paginator.setBackground({ color: 'transparent' })`를 사용하며 inline `!important`로 도서의 `:root`·`body` 배경이나 시스템 다크 모드용 도서 CSS가 일부 영역만 덮지 않게 합니다. 새 장과 테마 변경에도 같은 정책을 적용하고 글자색·페이지 배치는 유지합니다. 브라우저 강제 다크 모드 설정은 변경하지 않습니다. 실제 삼성 인터넷 PWA 수용 확인은 [TODO](../TODO.md)에 남깁니다.

`--viewer-theme-bg/text/border`는 현재 테마, `--viewer-reader-surface`는 리더 바의 표면을 나타냅니다. `--accent-400/500/600`은 `ACCENT_PALETTE`에서 가져오는 앱 포인트색이며 투명 interaction overlay에는 visible color를 추가하지 않습니다.

UI 폰트는 Pretendard, 본문은 선택된 reader font를 사용합니다. 첫 페인트와 hydration에서 테마가 튀지 않게 `layout.tsx`와 `BUILT_IN_THEME_COLORS`를 함께 유지합니다. 긴 도서 제목과 모바일 검색 결과에서 읽을 수 있는 폭·줄바꿈을 확보합니다.

본문 글꼴은 리디 바탕·조선 명조·조선 굴림·SANS 순서로 제공합니다. SERIF 선택 버튼은 제공하지 않지만 기존 serif 저장 설정과 글꼴별 fallback은 유지합니다. 추가 글꼴은 앱의 `public/fonts/`에 라이선스 고지와 함께 포함하고 선택한 글꼴만 sandbox 본문에 data URL로 넣습니다. 자동읽기 부모 문서에도 같은 글꼴을 선언해 선택 시 로딩합니다. 원본 조선일보 명조 TTF는 Chromium의 `vhea` 해석 오류로 사용할 수 없어 눈누의 기존 WOFF 배포본을 수정 없이 사용하며, 없는 글자는 serif 대체 글꼴로 표시합니다. 조선 굴림은 공식 원본 TTF를 사용합니다. 두 파일은 PWA 선택적 사전 캐시에 포함합니다. KoPub은 사용자 요청으로 제외했습니다.

간격은 기존 Tailwind scale을 사용합니다. 작은 컨트롤에 이미 적용된 uppercase label 패턴은 유지하되 모든 화면 문구를 대문자로 바꾸는 규칙으로 확대하지 않습니다.

## 메뉴·모달·모바일

압축 이미지 도서의 리더 미니바에는 `독서 통계` 바로 왼쪽에 아이콘 전용 `웹툰 모드` 토글을 둡니다. 켜졌을 때 포인트색을 사용하고 접근성 이름·툴팁과 눌림 상태를 제공합니다. 메뉴 표면의 눌림 상태 규칙으로 기본 재질 글자색보다 포인트색을 우선하며 SVG 아이콘도 이를 상속합니다. PDF와 EPUB/TXT에는 이 버튼을 표시하지 않습니다. 읽기·저장 동작은 [리더 사양](reader-and-progress.md#압축-이미지-웹툰-모드)을 따릅니다.

본문 선택 메뉴는 위쪽에 정사각형 색상 팔레트, 아래쪽에 아이콘 액션을 두는 두 줄 배치입니다. 팔레트와 액션은 같은 다섯 열에 정렬하고 닫기 버튼은 두지 않습니다. 공유 미지원 환경에서는 해당 칸을 비워 정렬을 유지합니다. 액션의 접근성 이름과 툴팁은 유지하며 짧은 폭에서도 한 줄에 배치합니다.

일반 목록·설정·확인 창은 공통 `ReaderModalFrame`/`MenuSheetHeader`와 시트 스타일을 사용합니다. 데스크톱 중앙 배치와 모바일 하단 시트, safe-area, 내부 스크롤, 헤더/푸터 고정 규칙을 함께 유지합니다. 검색은 별도 Spotlight 배치를 사용합니다. Escape·backdrop·포커스 복귀·브라우저 back의 동작은 각 컴포넌트의 dismiss/처리 중 계약을 따릅니다.

공통 제목 헤더는 처음 높이의 약 70%인 약 45px 높이와 32px 닫기 버튼, 기존보다 1px 작은 제목(모바일 15px/큰 화면 17px)을 사용합니다. 헤더 아래 구분선과 제목 아래 부제는 표시하지 않습니다. 목차·라이브러리 주석·정렬/필터·메모·자동읽기·번역·동기화 충돌을 포함해 공통 헤더에서 부제 API를 제거했습니다. 통계 새로고침·로그인 안내 아이콘도 헤더 크기에 맞춥니다. 번역·주석 메모·동기화 충돌도 공통 헤더를 사용하며, 별도 확인 창의 메시지 중심 배치와 검색창·비모달 알림은 유지합니다.

모바일(639px 이하) `data-menu-sheet` 시트는 공통 헤더의 빈 영역이나 제목을 아래로 끌면 따라 내려옵니다. 64px 이상 또는 24px 이상의 빠른 아래 드래그로 닫고, 짧은 드래그·취소는 원위치로 돌아옵니다. 헤더 버튼에서 시작한 입력·본문 스크롤·데스크톱 중앙 모달은 닫기 제스처를 시작하지 않습니다. 닫기가 비활성화된 처리 중 상태도 따릅니다. 제스처 구현은 `useMenuSheetDrag`가 담당합니다.

도서 정보의 읽기·이미지 복사·이미지 저장·삭제는 헤더 오른쪽 아이콘 액션으로 표시합니다. 독서 통계는 JSON 저장·공유·진단·새로고침 순서로 헤더 오른쪽에 둡니다. 헤더 액션은 32px 정사각형 버튼과 16px 아이콘을 사용하고 접근성 이름·툴팁·비활성/처리 중 상태를 유지합니다. 삭제는 확인창을 거치며, 이미지 캡처에서 헤더 액션은 제외합니다. 상태 피드백은 도서 정보의 하단 상태 영역과 통계 본문에 표시합니다.

리더 설정의 크기 상세 펼침은 기존 구분선과 작은 화살표 형태에 포인트색만 적용합니다. 글꼴 선택은 줄바꿈 없이 한 줄을 유지하고 넘치면 가로 스크롤하며 스크롤바는 표시하지 않습니다. 마우스는 가로 드래그로 이동하며 드래그가 글꼴 선택으로 이어지지 않습니다. 트랙패드·터치는 기본 스크롤을 사용합니다.

[자동읽기](annotations-and-tools.md#자동읽기)는 모바일에서도 중앙 배치를 사용하는 컴팩트한 텍스트 모달입니다. 설정 폰트의 큰 단어 표시와 조밀한 컨트롤 간격을 사용하며, 공통 `MenuSheetHeader`·메뉴 재질·액션·강조 버튼 스타일로 기존 테마를 따릅니다. 복기 옵션 영역과 하단 사용 설명은 표시하지 않습니다. 배경 blur와 공통 포커스 잠금/복귀를 사용하며 작은 화면에서는 모달 내부를 스크롤합니다.

자동읽기 위치는 리더 메뉴 진행바 높이의 약 절반인 채움형 바이며, 현재/전체 단어 수를 내부 왼쪽에 작고 옅게 표시합니다. 장 전환 안내 문구는 두지 않고 속도는 별도 슬라이더로 조절합니다. 본문 표시 영역은 컨트롤보다 넉넉한 높이를 확보합니다.

진행률 임시 이동 확인은 비모달 패널이며 공통 포커스 차단 모달로 바꾸면 안 됩니다. 기능 계약은 [리더 사양](reader-and-progress.md#진행률-슬라이더의-임시-이동)에 있습니다. 작은 이동 안내가 닫혀도 필요한 원격 후보를 버리지 않습니다.

`동기화 지점으로 이동` 안내는 화면 오른쪽 아래에 고정된 비모달 알림입니다. safe-area와 하단 상태줄 위 여백을 유지하고 작은 화면에서도 이동·닫기 버튼이 잘리지 않게 합니다. 배치는 `SyncRecoveryNotice`가 담당하고 리더 메뉴 재질(`app-reader-menu-surface`)만 공유합니다. 바텀시트의 상대 위치·전체 너비 규칙을 알림에 적용하지 않습니다. 8초 자동 닫기와 명시적 이동 동작은 유지합니다.

## 고정 레이아웃 제스처

PDF·이미지 도서 확대·pan은 투명 interaction overlay를 사용합니다. 전체 화면 overlay의 `inset-0` 배치를 유지합니다. overlay는 콘텐츠 위·리더 chrome 아래에 있으며 레이아웃을 밀거나 색/여백/그림자/설명 문구를 추가하지 않습니다. 확대 제스처 자체를 위한 별도 버튼이나 저장 설정은 두지 않습니다. 압축 이미지 웹툰 모드는 위의 별도 토글을 사용합니다. pointer 종료·capture 상실·취소 때 pending frame과 제스처 상태를 정리하고 뒤따르는 클릭이 페이지를 넘기지 않도록 합니다.

제스처 조작에는 즉시 scale을 반영할 수 있습니다. 장식적인 이동은 transform/opacity/filter 범위와 reduced-motion을 고려합니다. 기존 tonal surface와 modal shadow를 사용합니다.

## 독립 디자인 키트

[ui-kit/README.md](../../ui-kit/README.md)가 키트 사용법의 유일한 유지 위치입니다. [ADOPT.md](../../ui-kit/ADOPT.md)와 [COVERAGE.md](../../ui-kit/COVERAGE.md)는 다른 프로젝트에 전달할 시각 적용 범위와 누락 점검을 담당합니다. 키트는 도메인/API/계정/저장 동작을 포함하지 않습니다. 대상 앱의 기존 기능과 수명·접근성 계약을 유지합니다.

`node --import tsx ui-kit/scripts/sync-tokens.mjs`는 원본의 토큰을 추출합니다. `components.css` 레시피와 coverage는 자동 갱신되지 않습니다. 복사 가능한 키트의 상대 경로와 라이선스는 유지합니다. 네이티브 `<dialog>` 카탈로그의 blur 결과와 앱 portal 모달의 결과는 다를 수 있으므로 Safari 실기기 확인은 [TODO](../TODO.md)에 보존합니다.
