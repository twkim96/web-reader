# 서재와 도서 파일

## 책장

클라우드 서재는 연결된 Drive 계정의 확정된 `web viewer` 폴더에 있는 직접 자식 도서를 표시합니다. 로컬 서재는 현재 브라우저 프로필에 저장한 파일을 표시하며 오프라인에서 사용할 수 있습니다. 폴더 선택·권한·재연결은 [Drive 연동](../integrations/firebase-and-drive.md)이 담당합니다.

제목 검색, 제목/최근/인기 정렬, 출처·장르·태그·형식 복수 선택 필터를 제공합니다. 형식 필터는 TXT, EPUB, PDF, ZIP이며 변환된 TXT는 원본 형식으로, ZIP·CBZ·7z는 ZIP으로 분류합니다. 형식 필터는 공개 카탈로그가 로딩 중이어도 사용할 수 있습니다. 검색·필터 초기화는 정렬 설정을 유지합니다.

목록·표지·압축 표지 보기를 지원합니다. 저장된 `grid` 설정은 압축 표지 보기로 이어집니다. 카드의 정보 버튼과 길게 누르기는 도서 정보창을 열고, 본문 진입과 분리됩니다. 책장은 로컬 표지 캐시만 읽고 진입/스크롤 중 원본이나 외부 표지를 다시 요청하지 않습니다. 성공한 도서 열기에서 내장 표지 또는 플랫폼 fallback을 캐시하며, 없으면 자동 생성 표면을 사용합니다. 진행도 0.0%와 100%는 읽는 중 우선 정렬에서 제외합니다.

도서 정보창은 헤더 오른쪽에 읽기·이미지 복사·이미지 저장·삭제 아이콘을 배치합니다. 표지와 독서 정보를 PNG로 저장하거나 지원되는 브라우저에서 이미지로 복사하며, PNG에는 헤더 액션을 포함하지 않습니다. 삭제는 기존 확인창을 거칩니다. PNG에는 화면에서 불러온 로컬 표지를 같은 비율과 구도로 그립니다. 이미지 생성기는 정보창과 함께 로드해 첫 오프라인 내보내기에서 추가 JavaScript 다운로드가 필요하지 않게 합니다. 복사는 사용자 클릭 중 PNG Promise를 `ClipboardItem`에 전달해 브라우저의 사용자 활성화 조건을 유지합니다. 미지원·권한 거부·생성 실패는 상태 문구로 알립니다.

제목 표시 설정은 [화면 사양](interface.md#테마설정재질)을 따릅니다. 제목 검색은 설정의 켜짐·꺼짐과 관계없이 원본 제목과 요약 제목 모두를 찾습니다. 정렬 기준과 도서 식별은 원래 제목·ID를 유지하며, 요약이 같은 여러 도서도 합치지 않습니다. 라이브러리 주석의 도서 선택지에서 표시 제목이 겹치면 원본 파일명·형식·크기·ID로 구분합니다.

목록 카드의 오른쪽 정보는 작은 파일 형식과 조회수를 `txt, 123만 조회`처럼 한 줄로, 그 아래 진행률과 진행 막대로 묶습니다. 도서 정보 `…` 버튼은 이 묶음의 맨 우측에 배치합니다. 조회수가 없으면 형식만 표시하고 쉼표는 생략합니다. 모바일·큰 화면 모두 표지·제목/태그/날짜·오른쪽 정보의 세 열을 사용해 정보 버튼 때문에 별도 행이 늘어나지 않게 합니다.

## 마이페이지 (로컬 시안)

도서목록·위시리스트·읽은 책·내 평가의 정렬은 이 브라우저에서 계정과 메뉴별로 기억합니다. 공개 프로필의 평가 정렬은 같은 브라우저에서 공통으로 기억합니다. 저장값을 읽을 수 없거나 선택지에 없으면 해당 메뉴의 기본 정렬을 사용합니다.

같은 로그인 세션에서 위시리스트, 내 평가, 대시보드 평가 미리보기의 최신 응답을 각각 하나씩 메모리에 보관합니다. 재진입 때 바로 표시하며, 최근 1분 안에 확인한 목록은 일반 복귀에서 다시 조회하지 않습니다. 이후 복귀, 명시적 다시 불러오기, 온라인 복구에서는 최신 목록을 확인합니다. 확인 중에도 이미 받은 목록과 편집 상태를 사용하며, 같은 목록의 진행 중인 조회는 공유합니다. 계정 전환·인증 거절 때 이전 응답을 폐기합니다. 저장·삭제·가져오기와 진행 중인 조회가 겹치면 응답 수명과 쓰기 결과를 확인합니다. 완료된 위시리스트 쓰기는 서버가 반환한 상태를 적용하고, 평가 쓰기나 충돌 뒤에는 해당 목록을 다시 확인합니다. 편집은 서버 조회·저장 결과의 최신 확인 버전과 삭제 기록을 사용합니다. 읽은 도서 줄은 메타데이터 조회 묶음이 끝나기 전에도 매칭된 책부터 표시합니다. 같은 독서 기록을 처리하는 동안 파일별 시간을 한 번 계산하고, 메타데이터가 도착하면 작품 연결과 목록 순서를 다시 계산합니다.

서재 도크의 주석 진입점을 마이페이지 아이콘으로 교체합니다. `/#mypage`는 전체 화면이며 대시보드·도서목록·둘러보기·읽은 책·위시리스트·내 평가·캘린더·통계·주석을 제공합니다. 하위 메뉴는 `#mypage/<menu>` 주소와 브라우저 뒤로가기를 사용합니다. 초기 인증·Drive 로딩을 마친 뒤 엽니다. 운영 배포 전 로컬과 Vercel 프리뷰에서 검토합니다.

대시보드는 위시리스트, 추천 도서, 평점을 남긴 도서, 읽은 도서를 이 순서로 표시합니다. 각 가로 줄에 최대 12권의 표지와 제목을 표시하며, 평점을 남긴 도서에는 내 별점도 표시합니다. 전체 보기에서 위시리스트·추천 도서·읽은 책·내 평가 목록을 엽니다. 내 평가에는 저장한 평가를 정렬해 표시하며, 평가가 없거나 로그인하지 않은 경우 해당 안내를 표시합니다. 아래에는 오늘·이번 달·전체 독서 시간, 월별 독서 캘린더와 선택일 기록을 표시합니다. 같은 달력과 날짜별 기록은 기록의 캘린더 탭에서도 엽니다. 자정과 앱 복귀 시 독서 시간 요약과 상세 통계의 기간 기준을 갱신하고, 달력에서 선택한 날짜는 유지합니다. 집계·동기화 계약은 [독서 통계](reading-statistics.md)를 따릅니다. 상세 통계는 기존 통계 컴포넌트를 페이지에 삽입해 사용합니다. 마이페이지의 [주석](annotations-and-tools.md#저장검색내보내기)은 검색·필터·내보내기를 제공하는 독립 목록입니다.

마이페이지 화면 설정의 추천 도서 보기는 기본으로 켜져 있으며, 선택은 브라우저에 저장합니다. 끄면 홈 추천 줄을 숨깁니다. 추천 도서는 이미 받아온 위시리스트와 읽은 도서에서 최근 작품을 각각 최대 12권 사용합니다. 같은 작품·태그는 한 번만 세며, 추천 계산에는 공백과 영문 대소문자를 통일하고 의미가 같은 일부 플랫폼 표기를 묶습니다. 관심 작품에서 반복되는 태그와 카탈로그에서 덜 흔한 태그에 더 높은 가중치를 줍니다. 관심 작품에 붙은 태그가 많을수록 각 태그가 취향에 기여하는 양을 조금씩 낮춥니다. 태그 빈도에 완충값을 더해 소수 작품에만 붙은 태그가 여러 태그의 일치를 압도하는 경우를 줄입니다. 고유 태그가 6개를 넘는 후보에는 완만한 감점을 적용하며, 태그가 적은 후보에 별도 가산점을 주지 않습니다. 플랫폼별 순위를 정규화한 인기 점수로 후보를 거르고 현재 목록에서 확인한 위시리스트·읽은 도서와 공유 태그가 없는 후보를 제외합니다. 기존 관련성 기준을 통과한 전체 후보에서 최대 50권을 중복 없이 가중 추첨합니다. 후보가 한 플랫폼에 몰릴수록 상대적으로 적은 플랫폼 작품의 추첨 가중치에 최대 20%를 더합니다. 후보마다 작품 하나의 비중을 링크가 있는 플랫폼에 나눠 계산합니다. 홈은 처음 12권까지 표시하고, 전체 보기는 같은 작품을 세로 목록으로 열어 정렬과 위시리스트 담기를 제공합니다. 추천이 없으면 홈 영역을 생략합니다. 마이페이지에 들어올 때 추첨 기준을 새로 정하고, 내부 메뉴·도서 상세를 오가는 동안에는 그 기준을 유지합니다. 이미 추천에 표시된 작품을 위시리스트에 담으면 그 방문의 추천 줄을 유지합니다. 다음 마이페이지 진입이나 새로고침에서 최신 위시리스트를 반영해 추천에서 제외합니다. 브라우저의 탐색 인덱스와 이미 받아온 목록으로 계산합니다.

도서목록은 최초 진입 때 앱에 포함된 [공개 탐색 인덱스](../operations/book-metadata-publishing.md#도서-탐색-인덱스)를 한 번 읽습니다. 로딩·검증·작품 묶기 결과를 같은 앱 실행에서 공유하고, Firestore 상세 버킷 전체를 읽지 않습니다. 카탈로그의 검색어·필터·정렬 준비는 도서목록이 표시될 때 수행하고 화면을 다시 열 때 재사용합니다. 목록에 표시 중인 범위와 상관없이 전체 탐색 인덱스에서 제목과 작가명을 검색합니다. 작가명이 있는 작품은 목록과 상세에 표시합니다. 검색창에서 `#회귀`처럼 입력하면 전체 태그의 부분 일치 후보를 자동완성으로 보여줍니다. `#ㄱㅇ`처럼 초성만 입력하면 태그의 시작 초성이 일치하는 후보를 해당 도서가 많은 순으로 보여줍니다. 자동완성 후보는 한 줄에 표시하며 넘치는 후보는 좌우로 스크롤합니다. 선택한 태그는 검색창에 포인트색으로 표시하고 누르면 뺍니다. 태그를 여러 개 선택하면 모두 가진 작품을 제목·플랫폼·장르 조건과 함께 찾습니다. 플랫폼·장르·상위 태그 필터, 인기·조회/다운로드·제목 정렬을 지원하고 한 번에 60권씩 표시합니다. 태그 필터에서 자주 쓰이는 태그 120개를 가나다순으로 표시합니다. 같은 플랫폼 작품 링크로 이어진 항목은 작품 하나로 묶으며, 제목 검색은 묶인 별칭 제목에도 적용합니다. 상세에는 해당 작품의 모든 게시 플랫폼 링크를 표시합니다. 위시리스트는 공개 작품 키로 항목을 식별하고 최근 담은 순·인기순·조회/다운로드순·가나다순으로 정렬합니다. 검색과 플랫폼·장르·태그 필터는 도서목록에서 제공합니다. 앱 요청으로만 수집된 도서는 다음 정식 게시 원본에 포함될 때 탐색에 나타납니다.

게스트 위시리스트는 현재 브라우저의 localStorage에 보관합니다. 로그인한 계정의 위시리스트와 평가는 Firebase 인증을 확인하는 마이페이지 API를 통해 Firestore에 저장하며 같은 계정의 기기에서 이어집니다. 시안의 브라우저 저장분은 공개 설정에서 확인 후 가져올 수 있습니다. 계정에 같은 작품의 기존 항목이나 삭제 기록이 있으면 계정 상태를 유지합니다. 평가는 저장된 플랫폼 작품 링크 또는 유일하게 확인되는 제목을 기준으로 가져옵니다. 작품을 확정할 수 없는 평가는 브라우저에 보존하고 가져오기 결과에 표시합니다.

개인 위시리스트의 [한 문서 조회](../operations/deployment-and-recovery.md#개인-위시리스트-한-문서-조회)는 서버에서 활성화할 수 있습니다. 계정의 모든 작품별 상태에서 요약을 처음 만들고 이후 개인 목록은 요약 한 문서를 읽습니다. 책을 빼면 담은 목록에서 제거하고, 같은 문서에 작품 키·삭제 버전·정렬 시각을 남깁니다. 작품별 원본과 요약은 한 트랜잭션에서 갱신합니다. 공개 프로필과 둘러보기는 공개 설정을 확인한 뒤 작품별 원본의 담은 항목을 조회합니다.

대시보드의 추천 도서 아래에는 최근 읽은 책을 표시하고 별도 메뉴에서 전체 목록을 봅니다. 로그인 계정의 동기화 완료 독서 세션 중 숨기지 않은 기록을 사용합니다. 현재 서재에서 파일이 삭제됐어도 세션이 남아 있으면 표시합니다. 같은 플랫폼 작품 링크로 이어진 파일은 한 권으로 묶으며, 제목 키가 같아도 플랫폼 링크가 서로 연결되지 않는 판본은 따로 표시합니다. 같은 파일의 기록이 서로 다른 작품을 가리키면 집계에서 해당 파일의 작품 연결을 보류합니다. 일치하는 메타데이터가 있는 책만 표시합니다. 화면에 필요한 매칭 결과를 기기에서 재사용하며, 현재 앱 빌드에서 서버가 확인한 매칭은 최대 한 시간, 확인된 미매칭은 최대 5분간 유효합니다. 메모리의 메타데이터 문서를 재사용하면 원래 서버 조회 시각을 보존합니다. 캐시에는 계정과 제목의 해시 및 공개 메타데이터만 저장합니다. 독서 시간과 진행률은 현재 계정의 세션에서 매번 계산합니다. 독서 시간은 기존 통계의 중복 시간 집계를 사용하며 진행률은 세션의 최고 진행률입니다.

대시보드는 최근 작품을 표시하는 데 필요한 제목부터 조회합니다. 대시보드와 읽은 책이 동시에 독서 세션을 요청하면 같은 계정의 IndexedDB 조회를 공유합니다. 이후 요청은 새 스냅샷을 읽고 화면별 통계·숨김·동기화 기준은 각자 적용합니다. 전체 읽은 책 목록에서 평가와 집계를 표시합니다. 보관된 매칭과 새로 확인한 항목부터 표시합니다. 표시할 도서가 이미 있으면 남은 매칭은 목록을 가리지 않고 진행합니다. 조회 실패는 캐시하지 않으며 재시도할 수 있습니다. 탐색 인덱스를 받아오는 중에도 읽은 책을 표시하고, 게시 작품이 확인되면 상세 링크를 활성화합니다. 화면을 떠나면 아직 시작하지 않은 조회를 취소합니다.

읽은 책·내 평가 목록, 대시보드의 읽은 도서·평점을 남긴 도서 줄과 도서 상세는 화면 근처의 네이버·카카오 표지를 페이지 주소 전송 없이 원본에서 먼저 받습니다. 원본이 실패하면 앱의 표지 프록시로 한 번 재시도합니다. 노벨피아 등 다른 주소는 처음부터 프록시를 사용합니다. 마이페이지의 작품에 표지가 없거나 이미지를 불러오지 못하면 작품 제목으로 서재와 같은 방식의 대체 표지를 표시합니다.

읽은 책 목록은 표지 옆에 제목·읽은 시간과 진행률·별점을 차례로 표시합니다. 목록 제목 옆에서 최근 읽은 순·읽은 시간순·진행률순·가나다순을 선택할 수 있습니다. 내 평가와 공개 프로필의 평가 목록은 최근 평가순 또는 별점이 높은 순·낮은 순으로 정렬합니다. 공개 평가 정렬은 더 보기로 불러올 항목까지 포함합니다. 미평가 도서에는 빈 별 다섯 개를 표시합니다. 목록의 별을 누르면 도서 상세의 별점에 초점을 맞춥니다. 상세에서는 출처 바로 아래에 별점을 표시하며, 별을 누르면 선택 한줄평과 저장·삭제 버튼을 엽니다. 로그인 계정은 도서목록에서 찾은 작품도 독서 기록 없이 평가할 수 있습니다. 별점은 0.5점부터 5점까지 0.5점 단위로 매기며, 별의 왼쪽과 오른쪽으로 반점과 정수 점수를 고릅니다. 별점·한줄평은 계정과 작품별 문서로 저장합니다. 요청형 메타데이터의 제목이 달라도 게시된 플랫폼 링크가 같은 작품을 가리키면 같은 평가를 불러옵니다. 작품을 구분하는 플랫폼 링크가 엇갈리거나 평가 대상이 여러 개면 상세에서 수정·삭제를 막습니다. 평가에는 독서 시간과 최고 진행률도 표시합니다. 상세 주소를 직접 열거나 목록에서 들어와도 현재 확인된 작품 연결로 동기화 세션의 시간과 최고 진행률을 계산합니다. 도서 상세도 읽은 책과 같은 기기 메타데이터 캐시를 사용합니다. 목록이 기억한 파일 연결은 개인 독서 기록 표시에 사용합니다. 공개 평가의 독서 수치는 현재 작품과 연결이 확인된 파일의 세션만 합산합니다. 미연결 파일이 있더라도 확인된 세션은 사용할 수 있습니다. 조회 실패나 확인된 파일의 연결 충돌이 있거나, 일부 연결을 확인할 수 없어 이전 수치보다 작게 집계되면 별점과 한줄평을 먼저 저장하고 기존 수치를 유지합니다. 저장 트랜잭션은 같은 평가 버전에 뒤늦게 보완된 수치까지 확인합니다. 일부만 연결했거나 연결 범위 정보가 없는 초기 형식의 스냅샷은 기존 수치를 낮출 수 없습니다. 전체 연결을 확인한 최신 스냅샷은 기존 수치를 교체할 수 있습니다. 수치가 비어 있는 평가에는 서버에서 파일 연결을 확인한 독서 기록으로 응답 후 보완할 수 있습니다. 같은 저장 요청의 재시도는 보완을 다시 예약하지 않으며, 늦게 나온 결과는 수정하거나 삭제한 평가에 적용하지 않습니다. 내 평가 메뉴에서는 독서 기록을 숨겼거나 작품이 카탈로그에서 빠졌을 때도 저장한 평가를 삭제할 수 있습니다. 삭제한 위시리스트와 평가는 최신 삭제 버전 번호를 확인한 뒤 다시 등록할 수 있습니다. 여러 작품 키가 같은 작품으로 합쳐진 위시리스트는 각 키의 정확한 최신 버전을 한 트랜잭션에서 확인해 함께 삭제합니다. 게시 인덱스에서 빠진 키는 서버 메타데이터에서 같은 작품으로 확인되는 경우에만 포함합니다. 다른 기기에서 먼저 변경했다면 위시리스트를 자동으로 다시 조회합니다.

도서 상세에서 평가를 저장하면 별점과 한줄평을 즉시 표시합니다. 저장이 완료되면 이미 열려 있는 내 평가 목록도 갱신합니다. 삭제 전에 시작한 조회는 삭제 성공 뒤 무효화하며, 탭으로 돌아오면 계정의 최신 평가를 가져옵니다. 서버 저장 중에는 같은 평가의 다음 수정을 잠시 막습니다. 일시적인 통신·서버 오류는 같은 저장 ID로 최대 두 번 재시도합니다. 저장을 확인할 수 없으면 확정된 이전 평가를 표시하고 계정 기록을 다시 조회합니다. 상세의 별점·한줄평 초안은 편집기에 남습니다. 서버의 평가 버전이 달라졌으면 최신 평가에 초안을 적용할지 사용자가 선택한 뒤 다시 저장합니다.

대시보드에서 도서를 누르거나 위시리스트, 읽은 책, 도서목록에서 행의 도서 정보 영역을 누르면 작품별 `#mypage/book/<workId>` 주소의 상세 페이지를 엽니다. 읽은 책의 요청형 메타데이터가 게시 인덱스의 작품으로 연결되면 상세 주소에 게시 작품 ID를 사용해 새로고침과 새 탭에서도 열립니다. 탐색 인덱스를 조회하지 못했거나 일치하는 게시 작품을 확인할 수 없으면 상세 링크를 제공하지 않습니다. 목록의 플랫폼 이름은 텍스트이며 외부 링크는 상세 페이지에 있습니다. 상세에서 돌아가면 이전 마이페이지 목록으로 복귀하며, 읽은 책의 펼친 목록과 스크롤 위치를 유지합니다. 공개 메타데이터의 표지·장르·태그·플랫폼을 표시합니다. 각 플랫폼의 링크와 수치를 위아래로 놓고, 출처는 세로 구분선이 있는 가로 한 줄로 표시합니다. 좁은 화면에서는 출처 줄을 좌우로 스크롤할 수 있습니다. 작품 소개가 있으면 상세에서 해당 [소개글 파일](../operations/book-metadata-publishing.md#도서-탐색-인덱스)을 요청해 표시합니다. 기본정보 상단의 하트는 위시리스트 상태를 나타내며 읽은 세션이나 저장된 진행률이 있으면 왼쪽에 체크를 표시합니다. 상세 주소를 직접 열어도 기존 메타데이터 별칭과 플랫폼 작품 링크로 현재 계정의 독서 기록을 연결합니다. 같은 제목의 매칭은 한 번 계산하고 그 제목을 가진 각 파일의 충돌 여부와 독서 기록에 적용합니다. 수동 책갈피는 현재 계정의 로컬 책갈피에서 가져오고, 내 독서 기록에는 읽은 시간과 진행도를 왼쪽에 나란히 표시합니다. 진행도는 저장된 세션의 겹치거나 맞닿은 읽기 범위를 합친 뒤, 폭이 2%p 이상인 구간의 끝값 중 최댓값을 표시합니다.

도서 상세의 책갈피 목록은 처음에 접혀 있으며 제목을 눌러 펼치고 접을 수 있습니다. 내 독서 기록 아래에는 연관 도서 표지와 제목을 작은 가로 스크롤 목록으로 최대 12권 표시합니다. 이미 불러온 공개 탐색 인덱스에서 현재 작품과 같은 태그를 가진 작품을 찾고, 덜 흔한 태그에 더 큰 가중치를 줍니다. 같은 작품의 별칭은 하나로 묶고 현재 작품은 제외합니다. 관련성이 충분한 후보가 한 플랫폼에 몰리면 전체 후보를 대상으로 최대 12권을 가중 추첨합니다. 추천 도서와 같은 플랫폼 가산점을 쓰고, 태그 관련성이 높은 작품에 더 큰 추첨 가중치를 줍니다. 같은 마이페이지 방문 동안 순서를 유지합니다. 공유 태그가 없으면 연관 도서 영역을 생략합니다. 표지는 화면 근처에서 불러오고, 목록을 만드는 데 추가 Firestore 조회는 없습니다. 연관 도서를 열면 뒤로가기로 이전 상세에 돌아옵니다.

도서 상세의 내 평가는 해당 작품과 게시 인덱스에 연결된 별칭의 평가·삭제 버전만 조회합니다. 보관함에서 전체 목록을 여는 경우는 전체 조회를 사용합니다.

공개 설정에서 닉네임을 바꾸고 **별점 및 평가 공개**와 **위시리스트 공개**를 각각 전환합니다. 새 계정의 기본값은 평가 공개, 위시리스트 비공개입니다. 기존 두 설정 값과 닉네임 변경 전의 고유 ID 코드는 유지합니다. 읽은 책 목록은 본인만 볼 수 있습니다.

피드는 다른 사용자의 평가와 위시리스트를 탭으로 나눕니다. 해당 항목이 공개된 다른 사용자의 도서를 사용자별 가로 줄에 최대 12권씩 표시합니다. 공개할 항목이 없는 계정만 있는 페이지는 요청당 최대 네 페이지까지 확인합니다. 위시리스트는 최근에 저장한 순서로 12건을 조회하고 공개 도서로 연결된 작품을 표시합니다. 표지를 누르면 도서 상세를 열고, 줄의 전체 보기나 도서 상세의 평가 작성자 닉네임을 누르면 해당 사용자의 공개 마이페이지 `/people/<code>`를 엽니다. 두 항목을 모두 비공개로 하면 공개 프로필도 숨깁니다.

공개 프로필의 커서 조회는 카드와 정렬에 필요한 공개 후보를 읽고, 같은 공개 작품의 여러 기록 중 최신 기록을 골라 최대 30권씩 나눕니다. 목록이 한 페이지보다 크면 같은 서버에서 변경 없는 후보를 재사용합니다. [서버 후보 캐시](../operations/deployment-and-recovery.md#공개-프로필-후보-캐시)는 Firestore의 변경 여부를 대조하며 작품 연결과 권한 확인은 요청마다 수행합니다. 마지막 기록의 정렬값과 작품 ID를 암호화해 다음 페이지의 시작점으로 씁니다. 앞쪽 항목을 지워도 뒷부분을 건너뛰지 않으며 정렬 중 앞쪽에 들어온 새 항목은 새로고침에서 확인할 수 있습니다. 공개 설정이 변경되면 열려 있던 목록을 다시 불러옵니다. 이전 PWA의 숫자 오프셋 요청도 지원합니다.

작품 상세는 최근 공개 평가 최대 20개와 전체 공개 별점의 평균 및 개수를 표시합니다. 한줄평 없이 남긴 별점도 집계합니다. 같은 작품 별칭에 등장하는 작성자의 공개 설정은 한 요청의 Firestore 스냅샷에서 한 번만 읽습니다. 평가 공개를 끈 계정의 평가는 타인의 목록과 작품 평균·개수에서 제외됩니다. [저장·공개 설계](../design/mypage-sharing.md)에 경로와 접근 계약이 있습니다.

현재 테마의 배경·글자·포인트색을 사용합니다. 영역과 목록의 시각 구분은 [마이페이지 화면 사양](interface.md#메뉴모달모바일)을 따릅니다. 넓은 화면에서는 캘린더와 일별 기록을 나란히 배치하고, 좁은 화면에서는 세로로 배치합니다.

구현은 `src/components/mypage/`, `useMyPageNavigation`, `useWishlist`, `bookDiscovery`, `readBookMetadata`, `readBooks`, `localBookReview`에 있습니다. 관련 회귀는 `test:shelf-ui`와 브라우저 회귀의 라이브러리 주석 경로를 사용합니다.

## 형식과 가져오기

| 원본 | 읽기와 로컬 보관 |
| --- | --- |
| TXT | 인코딩을 판별하고 EPUB으로 변환해 읽기용 캐시를 저장 |
| EPUB | EPUB 구조 검증 후 Foliate로 열기 |
| PDF | PDF.js와 Foliate의 고정 레이아웃 경로로 열고 원본 Blob 보관 |
| ZIP·CBZ·7z | 지원 이미지 항목을 검사·정렬해 고정 레이아웃 책으로 열고 원본 Blob과 검사 인덱스 보관 |

Drive 업로드는 사용자가 선택한 원본을 보존합니다. 로컬 TXT 캐시의 파일명이 EPUB으로 바뀌어도 `sourceFormat`을 유지합니다. PDF·압축 도서를 EPUB으로 변환한다는 가정은 사용하지 않습니다.

TXT 변환은 UTF-8·EUC-KR·UTF-16 계열 인코딩을 처리합니다. 변환/목차 변경은 새로 만드는 EPUB에 적용하며 기존 저장 EPUB을 임의로 다시 변환하지 않습니다.

일반 가져오기에는 파일 수·개별 용량·총용량 제한이 있고 압축 도서는 한 번에 하나만 단독 선택합니다. ZIP은 400MB, CBZ와 7z는 각각 300MB까지 가져오거나 원격에서 열 수 있습니다(1MB = 1,048,576바이트). 정확한 한도와 활성 형식은 [bookFormats.ts](../../src/lib/bookFormats.ts)의 `ACTIVE_SOURCE_FORMATS`, `BOOK_FILE_LIMITS_MB`, `updateImportSelection`이 기준입니다. 암호화된 압축과 손상·지원하지 않는 압축은 오류로 처리합니다. 이미지/압축 해제 한도는 [archiveImageBook.ts](../../src/lib/archiveImageBook.ts)를 기준으로 합니다.

ZIP은 Safari와 Apple 모바일 WebKit에서 Worker/stream 전송 정지를 피하려고 같은 스레드 대체 경로를 사용합니다. 7z는 Worker와 직렬 추출 큐를 사용하며 취소·타임아웃 시 작업과 자원을 정리합니다. PDF.js의 메인 실행과 Worker에는 `Map/WeakMap.getOrInsertComputed` 호환 처리가 있습니다.

## 캐시·삭제 계약

본문·메타데이터·표지·압축 검사 캐시는 `DEVICE_CONTENT_OWNER_KEY`의 기기 공용 공간에 속합니다. Firebase나 Drive 계정을 바꿔도 파일 캐시 소유권을 새 계정으로 옮기지 않습니다. 진행률·주석·통계는 별도 계정 공간입니다. 저장 구조와 업그레이드의 보존 범위는 [운영 가이드](../operations/deployment-and-recovery.md)에 있습니다.

책을 열 때 유효한 로컬 캐시를 우선 사용하고 필요한 경우 Drive에서 내려받습니다. `bookFingerprint`로 원본 호환성을 확인합니다. 저장 공간 부족을 일반 성공으로 처리하지 않으며, 취소된 이전 열기의 응답이 새 도서를 덮지 않아야 합니다.

클라우드 도서 삭제는 Drive 삭제 → 진행률 초기화 성공 → 로컬 콘텐츠 제거 순서입니다. 앞 단계가 실패하거나 계정 수명이 바뀌면 뒤 단계를 진행하지 않습니다. 도서 주석 삭제에는 generation/tombstone 경계가 있으므로 콘텐츠 제거만으로 원격 삭제가 끝났다고 판단하지 않습니다.

기기 사본이 있는 Drive 도서의 `로컬 삭제`는 기기 콘텐츠·메타데이터·표지·압축 검사 캐시를 제거하고 계정 진행률·주석과 Drive 원본은 유지합니다. `전체 삭제`는 위의 안전 삭제 순서를 사용합니다. 로컬 전용 도서의 삭제는 유일한 기기 사본에도 영향을 주므로 실제 삭제 범위를 확인창에서 구분합니다.
