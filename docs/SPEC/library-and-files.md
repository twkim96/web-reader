# 서재와 도서 파일

## 책장

클라우드 서재는 연결된 Drive 계정의 확정된 `web viewer` 폴더에 있는 직접 자식 도서를 표시합니다. 로컬 서재는 현재 브라우저 프로필에 저장한 파일을 표시하며 오프라인에서 사용할 수 있습니다. 폴더 선택·권한·재연결은 [Drive 연동](../integrations/firebase-and-drive.md)이 담당합니다.

제목 검색, 제목/최근/인기 정렬, 출처·장르·태그·형식 복수 선택 필터를 제공합니다. 형식 필터는 TXT, EPUB, PDF, ZIP이며 변환된 TXT는 원본 형식으로, ZIP·CBZ·7z는 ZIP으로 분류합니다. 형식 필터는 공개 카탈로그가 로딩 중이어도 사용할 수 있습니다. 검색·필터 초기화는 정렬 설정을 유지합니다.

목록·표지·압축 표지 보기를 지원합니다. 저장된 `grid` 설정은 압축 표지 보기로 이어집니다. 카드의 정보 버튼과 길게 누르기는 도서 정보창을 열고, 본문 진입과 분리됩니다. 책장은 로컬 표지 캐시만 읽고 진입/스크롤 중 원본이나 외부 표지를 다시 요청하지 않습니다. 성공한 도서 열기에서 내장 표지 또는 플랫폼 fallback을 캐시하며, 없으면 자동 생성 표면을 사용합니다. 진행도 0.0%와 100%는 읽는 중 우선 정렬에서 제외합니다.

도서 정보창은 헤더 오른쪽에 읽기·이미지 복사·이미지 저장·삭제 아이콘을 배치합니다. 표지와 독서 정보를 PNG로 저장하거나 지원되는 브라우저에서 이미지로 복사하며, PNG에는 헤더 액션을 포함하지 않습니다. 삭제는 기존 확인창을 거칩니다. 로컬 표지의 `blob:` URL과 캐시된 리소스 주소를 변형하지 않으며, 이미지 생성기는 정보창과 함께 로드해 첫 오프라인 내보내기에서 추가 JavaScript 다운로드가 필요하지 않게 합니다. 복사는 사용자 클릭 중 PNG Promise를 `ClipboardItem`에 전달해 브라우저의 사용자 활성화 조건을 유지합니다. 미지원·권한 거부·생성 실패는 상태 문구로 알립니다.

제목 표시 설정은 [화면 사양](interface.md#테마설정재질)을 따릅니다. 제목 검색은 설정의 켜짐·꺼짐과 관계없이 원본 제목과 요약 제목 모두를 찾습니다. 정렬 기준과 도서 식별은 원래 제목·ID를 유지하며, 요약이 같은 여러 도서도 합치지 않습니다. 라이브러리 주석의 도서 선택지에서 표시 제목이 겹치면 원본 파일명·형식·크기·ID로 구분합니다.

목록 카드의 오른쪽 정보는 작은 파일 형식과 조회수를 `txt, 123만 조회`처럼 한 줄로, 그 아래 진행률과 진행 막대로 묶습니다. 도서 정보 `…` 버튼은 이 묶음의 맨 우측에 배치합니다. 조회수가 없으면 형식만 표시하고 쉼표는 생략합니다. 모바일·큰 화면 모두 표지·제목/태그/날짜·오른쪽 정보의 세 열을 사용해 정보 버튼 때문에 별도 행이 늘어나지 않게 합니다.

## 마이페이지 (로컬 시안)

서재 도크의 주석 진입점을 마이페이지 아이콘으로 교체합니다. `/#mypage`는 전체 화면이며 대시보드·도서목록·둘러보기·읽은 책·위시리스트·내 평가·통계·주석을 제공합니다. 하위 메뉴는 `#mypage/<menu>` 주소와 브라우저 뒤로가기를 사용합니다. 초기 인증·Drive 로딩을 마친 뒤 엽니다. 운영 배포 전 로컬과 Vercel 프리뷰에서 검토합니다.

대시보드는 읽고 싶은 도서, 최근 읽은 도서, 최근 평점을 남긴 도서를 이 순서로 표시합니다. 각 가로 줄에 최대 12권의 표지와 제목을 표시하며, 평점을 남긴 도서에는 내 별점도 표시합니다. 전체 보기에서 위시리스트·읽은 책·내 평가 목록을 엽니다. 아래에는 오늘·이번 달·전체 독서 시간, 월별 독서 캘린더와 선택일 기록을 표시합니다. 캘린더의 일 합계와 상세는 중복 시간과 자정을 같은 방식으로 계산합니다. 선택일에는 같은 도서·독서 방식·저장된 시간대의 집계 구간이 5분 이내로 이어지면 한 행으로 묶습니다. 첫 집계 시작 시각과 실제 독서 시간의 합을 표시합니다. 휴식 시간은 합산에서 제외합니다. 집계·동기화 계약은 [독서 통계](reading-statistics.md)를 따릅니다. 상세 통계는 기존 통계 컴포넌트를 페이지에 삽입해 사용합니다. 마이페이지의 [주석](annotations-and-tools.md#저장검색내보내기)은 검색·필터·내보내기를 제공하는 독립 목록입니다.

도서목록은 최초 진입 때 앱에 포함된 [공개 탐색 인덱스](../operations/book-metadata-publishing.md#도서-탐색-인덱스)를 한 번 읽습니다. 로딩·검증 결과를 같은 앱 실행에서 공유하고, Firestore 상세 버킷 전체를 읽지 않습니다. 목록에 표시 중인 범위와 상관없이 전체 게시 메타데이터를 대상으로 제목을 검색합니다. 플랫폼·장르·상위 태그 필터, 인기·조회/다운로드·제목 정렬을 지원하고 한 번에 60권씩 표시합니다. 같은 플랫폼 작품 링크로 이어진 항목은 작품 하나로 묶으며, 제목 검색은 묶인 별칭 제목에도 적용합니다. 상세에는 해당 작품의 모든 게시 플랫폼 링크를 표시합니다. 위시리스트는 공개 작품 키로 항목을 식별하고 자체 정렬을 유지합니다. 앱 요청으로만 수집된 도서는 다음 정식 게시 원본에 포함될 때 탐색에 나타납니다.

게스트 위시리스트는 현재 브라우저의 localStorage에 보관합니다. 로그인한 계정의 위시리스트와 평가는 Firebase 인증을 확인하는 마이페이지 API를 통해 Firestore에 저장하며 같은 계정의 기기에서 이어집니다. 시안의 브라우저 저장분은 공개 설정에서 확인 후 가져올 수 있습니다. 계정에 같은 작품의 기존 항목이나 삭제 기록이 있으면 계정 상태를 유지합니다. 평가는 저장된 플랫폼 작품 링크 또는 유일하게 확인되는 제목을 기준으로 가져옵니다. 작품을 확정할 수 없는 평가는 브라우저에 보존하고 가져오기 결과에 표시합니다.

대시보드의 위시리스트 아래에는 최근 읽은 책을 표시하고 별도 메뉴에서 전체 목록을 봅니다. 로그인 계정의 동기화 완료 독서 세션 중 숨기지 않은 기록을 사용합니다. 현재 서재에서 파일이 삭제됐어도 세션이 남아 있으면 표시합니다. 공개 메타데이터에서 같은 정식 작품 키나 플랫폼 작품 링크를 찾은 파일은 한 권으로 묶습니다. 일치하는 메타데이터가 있는 책만 표시하며 읽은 제목에 필요한 문서만 조회하고 메모리에 재사용합니다. 독서 시간은 기존 통계의 중복 시간 집계를 사용하며 진행률은 세션의 최고 진행률입니다.

대시보드는 최근 작품을 표시하는 데 필요한 제목부터 조회합니다. 전체 읽은 책 목록에서 평가와 집계를 표시합니다. 어느 화면에서든 메타데이터가 확인된 항목부터 표시하며 조회에 실패한 제목만 재시도합니다. 화면을 떠나면 아직 시작하지 않은 조회를 취소합니다. 읽은 책의 표지는 앱의 표지 프록시를 통해 표시합니다.

읽은 책 목록은 표지 옆에 제목·읽은 시간과 진행률·별점을 차례로 표시합니다. 미평가 도서에는 빈 별 다섯 개를 표시합니다. 별을 누르면 도서 상세의 내 평가에 초점을 맞추며, 내 독서 기록 아래에서 별점과 선택 한줄평을 저장·수정·삭제할 수 있습니다. 로그인 계정은 도서목록에서 찾은 작품도 독서 기록 없이 평가할 수 있습니다. 별점·한줄평은 계정과 작품별 문서로 저장합니다. 요청형 메타데이터의 제목이 달라도 게시된 플랫폼 링크가 같은 작품을 가리키면 같은 평가를 불러옵니다. 평가에는 독서 시간과 최고 진행률도 표시합니다. 도서 상세에서 기기에 저장된 동기화 세션으로 계산한 값을 함께 보냅니다. 기기 값이 없으면 평가를 먼저 저장하고, 서버의 동기화 기록이 있으면 응답 후에 반영합니다. 조회가 실패하면 기존 수치를 유지하고, 늦게 나온 결과는 수정하거나 삭제한 평가에 적용하지 않습니다. 내 평가 메뉴에서는 독서 기록을 숨겼거나 작품이 카탈로그에서 빠졌을 때도 저장한 평가를 삭제할 수 있습니다. 삭제한 위시리스트와 평가는 최신 삭제 버전 번호를 확인한 뒤 다시 등록할 수 있습니다.

도서 상세에서 평가를 저장하면 별점과 한줄평을 즉시 표시합니다. 서버 저장 중에는 같은 평가의 다음 수정을 잠시 막습니다. 일시적인 통신·서버 오류는 같은 저장 ID로 최대 두 번 재시도합니다. 저장을 확인할 수 없으면 이전 평가를 표시하고 계정 기록을 다시 조회합니다.

대시보드에서 도서를 누르거나 위시리스트, 읽은 책, 도서목록에서 행의 도서 정보 영역을 누르면 작품별 `#mypage/book/<workId>` 주소의 상세 페이지를 엽니다. 목록의 플랫폼 이름은 텍스트이며 외부 링크는 상세 페이지에 있습니다. 상세에서 돌아가면 이전 마이페이지 목록으로 복귀하며, 읽은 책의 펼친 목록과 스크롤 위치를 유지합니다. 공개 메타데이터의 표지·장르·태그·플랫폼을 표시합니다. 기본정보 상단의 하트는 위시리스트 상태를 나타내며 읽은 세션이나 저장된 진행률이 있으면 왼쪽에 체크를 표시합니다. 상세 주소를 직접 열어도 기존 메타데이터 별칭과 플랫폼 작품 링크로 현재 계정의 독서 기록을 연결합니다. 수동 책갈피는 현재 계정의 로컬 책갈피에서 가져오고, 내 독서 기록에는 읽은 시간과 진행도를 한 줄로 표시합니다. 진행도는 저장된 세션의 겹치거나 맞닿은 읽기 범위를 합친 뒤, 폭이 2%p 이상인 구간의 끝값 중 최댓값을 표시합니다.

공개 설정에서 닉네임을 바꾸고 **별점 및 평가 공개**와 **위시리스트 공개**를 각각 전환합니다. 새 계정의 기본값은 평가 공개, 위시리스트 비공개입니다. 기존 두 설정 값과 닉네임 변경 전의 고유 ID 코드는 유지합니다. 읽은 책 목록은 본인만 볼 수 있습니다.

둘러보기는 평가와 위시리스트를 탭으로 나눕니다. 해당 항목이 공개된 다른 사용자의 도서를 사용자별 가로 줄에 최대 12권씩 표시합니다. 표지를 누르면 도서 상세를 열고, 줄의 전체 보기나 도서 상세의 평가 작성자 닉네임을 누르면 해당 사용자의 공개 마이페이지 `/people/<code>`를 엽니다. 두 항목을 모두 비공개로 하면 공개 프로필도 숨깁니다.

작품 상세는 최근 공개 평가 최대 20개와 전체 공개 별점의 평균 및 개수를 표시합니다. 한줄평 없이 남긴 별점도 집계합니다. 평가 공개를 끈 계정의 평가는 타인의 목록과 작품 평균·개수에서 제외됩니다. [저장·공개 설계](../design/mypage-sharing.md)에 경로와 접근 계약이 있습니다.

현재 테마의 배경·글자·포인트색을 사용합니다. 영역과 목록의 시각 구분은 [마이페이지 화면 사양](interface.md#메뉴모달모바일)을 따릅니다. 넓은 화면에서는 캘린더와 일별 기록을 나란히 배치하고, 좁은 화면에서는 세로로 배치합니다.

구현은 `src/components/mypage/`, `useMyPageNavigation`, `useWishlist`, `bookDiscovery`, `readBookMetadata`, `readBooks`, `localBookReview`에 있습니다. 관련 회귀는 `test:shelf-ui`와 브라우저 회귀의 라이브러리 주석 경로를 사용합니다.

## 형식과 가져오기

| 원본 | 읽기와 로컬 보관 |
| --- | --- |
| TXT | 인코딩을 판별하고 EPUB으로 변환해 읽기용 캐시를 저장 |
| EPUB | EPUB 구조 검증 후 Foliate로 열기 |
| PDF | PDF.js와 Foliate의 고정 레이아웃 경로로 열고 원본 Blob 보관 |
| ZIP·CBZ·7z | 지원 이미지 항목을 검사·정렬해 고정 레이아웃 책으로 열고 원본 Blob과 검사 인덱스 보관 |

Drive 업로드는 사용자가 선택한 원본을 보존합니다. 로컬 TXT 캐시의 파일명이 EPUB으로 바뀌어도 `sourceFormat`을 유지합니다. PDF·압축 도서를 EPUB으로 변환한다는 가정은 사용하지 않습니다.

TXT 변환은 UTF-8·EUC-KR·UTF-16 계열 인코딩을 처리합니다. 변환/목차 변경은 새로 만드는 EPUB에 적용하며 기존 저장 EPUB을 임의로 다시 변환하지 않습니다.

일반 가져오기에는 파일 수·개별 용량·총용량 제한이 있고 압축 도서는 한 번에 하나만 단독 선택합니다. ZIP은 400MB, CBZ와 7z는 각각 300MB까지 가져오거나 원격에서 열 수 있습니다(1MB = 1,048,576바이트). 정확한 한도와 활성 형식은 [bookFormats.ts](../../src/lib/bookFormats.ts)의 `ACTIVE_SOURCE_FORMATS`, `BOOK_FILE_LIMITS_MB`, `updateImportSelection`이 기준입니다. 암호화된 압축과 손상·지원하지 않는 압축은 오류로 처리합니다. 이미지/압축 해제 한도는 [archiveImageBook.ts](../../src/lib/archiveImageBook.ts)를 기준으로 합니다.

ZIP은 Apple 모바일 WebKit에서 Worker/stream 전송 정지를 피하려고 같은 스레드 대체 경로를 사용합니다. 7z는 Worker와 직렬 추출 큐를 사용하며 취소·타임아웃 시 작업과 자원을 정리합니다. PDF.js의 메인 실행과 Worker에는 `Map/WeakMap.getOrInsertComputed` 호환 처리가 있습니다.

## 캐시·삭제 계약

본문·메타데이터·표지·압축 검사 캐시는 `DEVICE_CONTENT_OWNER_KEY`의 기기 공용 공간에 속합니다. Firebase나 Drive 계정을 바꿔도 파일 캐시 소유권을 새 계정으로 옮기지 않습니다. 진행률·주석·통계는 별도 계정 공간입니다. 저장 구조와 업그레이드의 보존 범위는 [운영 가이드](../operations/deployment-and-recovery.md)에 있습니다.

책을 열 때 유효한 로컬 캐시를 우선 사용하고 필요한 경우 Drive에서 내려받습니다. `bookFingerprint`로 원본 호환성을 확인합니다. 저장 공간 부족을 일반 성공으로 처리하지 않으며, 취소된 이전 열기의 응답이 새 도서를 덮지 않아야 합니다.

클라우드 도서 삭제는 Drive 삭제 → 진행률 초기화 성공 → 로컬 콘텐츠 제거 순서입니다. 앞 단계가 실패하거나 계정 수명이 바뀌면 뒤 단계를 진행하지 않습니다. 도서 주석 삭제에는 generation/tombstone 경계가 있으므로 콘텐츠 제거만으로 원격 삭제가 끝났다고 판단하지 않습니다.

기기 사본이 있는 Drive 도서의 `로컬 삭제`는 기기 콘텐츠·메타데이터·표지·압축 검사 캐시를 제거하고 계정 진행률·주석과 Drive 원본은 유지합니다. `전체 삭제`는 위의 안전 삭제 순서를 사용합니다. 로컬 전용 도서의 삭제는 유일한 기기 사본에도 영향을 주므로 실제 삭제 범위를 확인창에서 구분합니다.
