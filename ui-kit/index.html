06

다른 프로젝트로 가져가기

폴더를 복사하고, 적용 범위를 함께 전달하세요

01 / 복사

ui-kit 폴더 전체를 대상 프로젝트로 옮기세요. 폰트와 질감도 함께 이동합니다.

02 / 적용

tokens.css → components.css 순서로 불러오고 .wr-kit 아래에 화면을 구성하세요.

03 / 확인

ADOPT.md의 프롬프트와 COVERAGE.md 체크리스트로 모달과 상태별 누락을 점검하세요.

최소 사용 예시 
<link rel="stylesheet" href="ui-kit/tokens.css">
<link rel="stylesheet" href="ui-kit/components.css">
<main class="wr-kit wr-texture" data-theme="midnight"
      data-material="glass" data-texture="grain">
  <section class="wr-panel">
    <button class="wr-button wr-button--primary">계속하기</button>
  </section>
</main>
